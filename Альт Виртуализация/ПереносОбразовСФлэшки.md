### Как перенести образы с флэшки на два отказоустойчивых сервера

Вставляем флэшку в один из физических серверов

Переходим в Shell(консоль) одной машины виртуализации и проверяем есть ли подключение флэшки

В консоле набираем команду ``lsusb``

<img width="1298" height="165" alt="image" src="https://github.com/user-attachments/assets/51266b1e-1288-4f83-87f2-423c79723cad" />

Видим отобразилась наша флэшка, проверим названия диска который ей выдало ``lsblk``

<img width="1184" height="626" alt="image" src="https://github.com/user-attachments/assets/f2fbc806-c422-4fc5-a2a9-d3fed077d796" />

Если мы видим, что наша флэшка отобразилась наша флэшка по команде ``df -hT``, значит она подключена к виртуальной машине, её надо отключить

<img width="1325" height="199" alt="image" src="https://github.com/user-attachments/assets/a159fe7b-3aef-4b1d-9512-b6b745a9da95" />

Далее посмотрим какой тип поддерживаем наша флешка командой ``blkid /dev/sdh1``

<img width="1212" height="587" alt="image" src="https://github.com/user-attachments/assets/85b6f78b-81ca-4e66-ae72-17e0db4a9cce" />

##### 1. Создайте точку монтирования
```bash
mkdir -p /mnt/usb
```
##### 2. Примонтируйте раздел
При использовании такого монтирования раздела возникнит ошибка:
```bash
mount /dev/sdh1 /mnt/usb
```
> - Если возникнет ошибка ``no valid filesystem type``:
- Это означает, что системе нужно явно подсказать тип файловой системы (например, если флешка отформатирована в Windows-форматах NTFS или exFAT).

###### Для NTFS:
```bash
mount -t ntfs-3g /dev/sdh1 /mnt/usb или mount -t ntfs3 /dev/sdh1 /mnt/usb
```

###### Для exFAT:
```bash
mount -t exfat /dev/sdh1 /mnt/usb
```

###### Для FAT32:
```bash
mount -t vfat /dev/sdh1 /mnt/usb
```
Далее, чтобы смонтировать с типом используем другую команду монтирования

В «Альт Виртуализации» (и ОС Альт) для работы с NTFS используется либо современный встроенный в ядро драйвер ``ntfs3``, либо классический ``ntfs-3g``

##### 2.1 Проверьте доступные модули NTFS (новый драйвер ядра ntfs3, есть в «Альт 11» по умолчанию)
```bash
# Поиск модулей, связанных с ntfs
find /lib/modules/$(uname -r) -name "*ntfs*" | grep -E "ntfs(\.ko|3\.ko)"
```
<img width="1166" height="226" alt="image" src="https://github.com/user-attachments/assets/b69fcae8-3330-4811-ac4a-1acdaf6ea519" />

##### 2.2 Загрузите модуль ntfs3:
```bash
modprobe ntfs3
```
##### 2.3 Проверьте, что модуль загружен:
```bash
lsmod | grep ntfs3
```
##### 2.4 Создайте точку монтирования, если её нет:
```bash
mkdir -p /mnt/usb
```
##### 2.5 Примонтируйте через новый драйвер ядра:
```bash
mount -t ntfs3 /dev/sdh1 /mnt/usb
```
##### 4. Проверьте результат
Если команда прошла без ошибок, проверьте содержимое флешки:
```bash
mount | grep sdh1
ls -l /mnt/usb
```
<img width="1139" height="294" alt="image" src="https://github.com/user-attachments/assets/986dc5b4-8c94-4b30-81a5-634faa3ba02f" />

Как мы видим диск примонтирован, теперь надо остановить ВМ и удалить старый диск на виртуальной машине для его замены

Скопировать командой новый образ жесткого диска vmdk и подключить его на первом сервере mx1
```bash
cd /mnt/usb/
qm importdisk 100 mx1.r51-disk1.vmdk local-lvm
```
Так как у нас флэшка подключена к одному серверу, на второй сервер мы образ *.vmdk и SSL-сертификаты переносим копированием, предворительно создав на нём такую же папку ``mkdir -p /mnt/usb/``
```bash
scp mx2.r51-disk1.vmdk root@10.113.174.54:/mnt/usb
```
<img width="1164" height="30" alt="image" src="https://github.com/user-attachments/assets/10f99e69-bfe1-4fc7-b15d-2a947a6ce455" />

Скопировать командой новый образ жесткого диска vmdk и подключить его на втором сервере mx2
```bash
cd /mnt/usb/
qm importdisk 101 mx2.r51-disk1.vmdk local-lvm
```
Далее, размонтируйте флэшку на первом сервере
```bash
umount /mnt/usb
```

