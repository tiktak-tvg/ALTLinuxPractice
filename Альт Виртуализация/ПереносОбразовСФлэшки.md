### Как перенести образы с флэшки на два отказоустойчивых сервера.

Вставляем флэшку в один из физических серверов.

Переходим в Shell(консоль) одной машины виртуализации и проверяем есть ли подключение флэшки.

В консоле набираем команду ``lsusb``

<img width="1298" height="165" alt="image" src="https://github.com/user-attachments/assets/51266b1e-1288-4f83-87f2-423c79723cad" />

Видим отобразилась наша флэшка, проверим названия диска который ей выдало ``df -hT``

<img width="1325" height="199" alt="image" src="https://github.com/user-attachments/assets/a159fe7b-3aef-4b1d-9512-b6b745a9da95" />


##### 1. Создайте точку монтирования
```bash
mkdir -p /mnt/usb
```
##### 2. Примонтируйте раздел
Используйте имя раздела из вашего лога (sdg1):
```bash
mount /dev/sdg1 /mnt/usb
```
> - Если снова возникнет ошибка ``no valid filesystem type``:
- Это означает, что системе нужно явно подсказать тип файловой системы (например, если флешка отформатирована в Windows-форматах NTFS или exFAT).

###### Для NTFS:
```bash
mount -t ntfs-3g /dev/sdg1 /mnt/usb
```

###### Для exFAT:
```bash
mount -t exfat /dev/sdg1 /mnt/usb
```

###### Для FAT32:
```bash
mount -t vfat /dev/sdg1 /mnt/usb
```


##### 2.1 Проверьте доступные модули NTFS
```bash
# Поиск модулей, связанных с ntfs
find /lib/modules/$(uname -r) -name "*ntfs*" | grep -E "ntfs(\.ko|3\.ko)"
```

##### 4. Проверьте результат
Если команда прошла без ошибок, проверьте содержимое флешки:
bash
ls -l /mnt/usb
