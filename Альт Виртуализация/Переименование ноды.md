#### Шаг 1. Подготовка и остановка ВМЗавершите работу всех виртуальных машин (ВМ) и контейнеров (CT) на этом узле.

Подключитесь к узлу по SSH под пользователем root.

#### Шаг 2. Изменение системного имени (Hostname)

Задайте новое имя узла в системе:
```bash
hostnamectl set-hostname НОВОЕ_ИМЯ
```
Откройте файл /etc/hosts через текстовый редактор (например, nano или mcedit):
```bash
nano /etc/hosts
```
Найдите строку с IP-адресом вашего узла и замените старое имя на НОВОЕ_ИМЯ. 
Сохраните файл.

#### Шаг 3. Перенос конфигураций ВМ
Так как конфигурации привязаны к имени узла в кластерной файловой системе pmxcfs, их нужно переместить в новую директорию:

Остановите службу кластера:
```bash
systemctl stop pve-cluster
```
Запустите файловую систему локально для редактирования:
```bash
pmxcfs -l
```
Перейдите в каталог узлов:
```bash
cd /etc/pve/nodes
```
#### Шаг 4. Cоздание структуры и копирование файлов
Cоздайте директории вручную и скопируйте только файлы конфигураций:

Создаем структуру каталогов для нового узла
```bash
mkdir -p r44-kostroma-r7-v02/qemu-server r44-kostroma-r7-v02/lxc
```
Копируем конфигурации виртуальных машин (если они есть)
```bash
cp r44-kostroma-r7-v01/qemu-server/* r44-kostroma-r7-v02/qemu-server/ 2>/dev/null
```
Копируем конфигурации контейнеров (если они есть)
```bash
cp r44-kostroma-r7-v01/lxc/* r44-kostroma-r7-v02/lxc/ 2>/dev/null
```
#### Шаг 5. Проверка результата
Убедитесь, что конфигурационные файлы успешно перенеслись в новую папку:
```bash
ls -l r44-kostroma-r7-v02/qemu-server/
ls -l r44-kostroma-r7-v02/lxc/
```
Теперь файловая система pmxcfs приняла конфигурации. 

Завершаем локальный процесс pmxcfs
```bash
killall pmxcfs
```
Запускаем штатную службу кластера
```bash
systemctl start pve-cluster
```
Обновляем SSL-сертификаты под новое имя узла
```bash
pvecm updatecerts --force
```
Перезагружаем сервер
```bash
reboot
```
