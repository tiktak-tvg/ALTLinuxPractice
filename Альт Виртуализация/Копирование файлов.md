Можно рекурсивно скопировать все содержимое каталога из Windows на Linux, например папку:
```bash
scp -r E:\ISO root@192.168.1.202:/home./
```
И наоборот, можно скопировать файл с удаленного сервера Linux на свой компьютер Windows 10:
```bash
scp.exe root@192.168.1.202:/home/CentOS-8.1.1911-x86_64.iso C:\public
```
