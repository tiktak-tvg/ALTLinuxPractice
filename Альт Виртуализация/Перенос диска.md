#### Что делать если вы создали ВМ и не в той директории создали диск, например, в хранилище local и у вас не получается сделать снапшот.
Например, конфигурацию **VM 103**: диск scsi0 находится на хранилище типа ``local (dir)`` и имеет формат raw.<br> 
Используйте команду ``qm config`` для детального сравнения двух машин.

Для "проблемной" ВМ и для ВМ, где снимки работают, выполните в SSH на сервере Proxmox:
```bash
qm config <VM_ID>
```

У виртуальной машины **103** диск находится на хранилище ``local (тип dir)``, а формат диска — ``raw``.

**local** — это обычная директория в файловой системе хоста (/var/lib/vz).Хранилище ``local`` имеет тип ``dir (обычная директория)``.<br> 
Для снимков на таком хранилище диск должен быть в формате ``qcow2``. 

**raw** — это формат «как есть», без поддержки снапшотов и тонкой подготовки.``raw`` не поддерживает снапшоты. Это и есть причина ошибки когда вы хотите сделать снапшот.

Proxmox не может создавать снапшоты для дисков в формате raw на хранилище типа dir. 

Для снапшотов необходимо, чтобы:

Хранилище было ``lvmthin (как local-lvm у VM 102) или ZFS, Ceph``.

На хранилище ``dir`` диск должен быть в формате ``qcow2``.

У вашей **VM 102** диск на ``local-lvm (lvmthin)`` — поэтому снапшоты работают. У **VM 103** — local + raw — не работают.

Соберём подробную информацию по диску ВМ 103

Первым делом — посмотрите конфигурацию VM 103

Выполните в консоли хоста:
```bash
qm config 103
```
Это покажет все диски, параметры и возможные проблемные устройства (прямой проброс диска, iso в приводе, наличие parent и т.д.).

Какой тип хранилища для дисков VM 103

Узнайте, где лежит диск (например, scsi0: local-lvm:vm-103-disk-0 или local:103/vm-103-disk-0.raw).

Выполните:
```bash
pvesm status
```
Посмотрите на строку с вашим хранилищем (например, local-lvm, local). 

В столбце Type должно быть lvmthin (для снапшотов) или dir с дисками в формате qcow2. 

Если тип lvm (толстый LVM) – снимки невозможны.

Узнайте формат диска

Если хранилище типа dir (каталог), то диск должен быть в формате qcow2. 

Проверьте:
```bash
qemu-img info /var/lib/vz/images/103/vm-103-disk-0.raw   # путь уточните
```
Если формат raw – снимки не поддерживаются.

##### Решение: преобразовать диск из raw в qcow2 и/или перенести на local-lvm.
✅ Решение 1: Преобразовать диск в qcow2 прямо на хранилище local

Этот способ не требует переноса на другое хранилище. Но учтите: производительность qcow2 чуть ниже, чем raw, и нужен свободный объём ≈ размер диска (150 ГБ временно).

Остановите ВМ
```bash
qm stop 103
```
Создайте образ qcow2 и скопируйте данные
```bash
qemu-img convert -f raw -O qcow2 /var/lib/vz/images/103/vm-103-disk-0.raw /var/lib/vz/images/103/vm-103-disk-0.qcow2
```
Измените конфигурацию ВМ, указав новый файл
```bash
qm set 103 --scsi0 local:103/vm-103-disk-0.qcow2,iothread=1,size=150G
```
Удалите старый raw-файл (убедившись, что всё работает)
```bash
rm /var/lib/vz/images/103/vm-103-disk-0.raw
```
Запустите ВМ
```bash
qm start 103
```
✅ Решение 2: Перенести диск на хранилище local-lvm (рекомендуется, если есть свободное место)

local-lvm — это LVM-thin, он отлично работает со снапшотами и даёт лучшую производительность.

Остановите ВМ
```bash
qm stop 103
```
Перенесите диск на local-lvm, при необходимости формат изменится автоматически
```bash
qm move-disk 103 scsi0 local-lvm --delete
```
Флаг --delete удалит старый файл после успешного переноса

(Опционально) если хотите явно указать формат raw или qcow2 — не нужно, lvmthin использует свои механизмы

Запустите ВМ
```bash
qm start 103
```
Если команда qm move-disk недоступна в вашей версии Proxmox (судя по выводу qm diskscan, она есть — qm disk move — это то же самое), используйте:
```bash
qm disk move 103 scsi0 local-lvm --delete
```
✅ Решение 3: Преобразовать диск и оставить на local, но сменить тип хранилища (не рекомендуется)

Можно переопределить хранилище local, чтобы оно работало как каталог с поддержкой qcow2-снапшотов. Но проще и надёжнее — решения 1 или 2.

После любого из решений попробуйте создать снапшот:
```bash
qm snapshot 103 test_snap --description "После исправления"
```
Если снапшот создался — проблема решена.
