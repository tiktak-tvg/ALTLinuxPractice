#### Пошаговая инструкция по сбросу пароля

##### Шаг 1: Найдите и смонтируйте вашу систему

Ваша основная система находится на жестком диске, и ее сначала нужно подключить (смонтировать). В ALT Linux Rescue для этого есть удобная команда:

```bash
mount-system
```
Эта команда автоматически найдет ваши Linux-разделы и смонтирует их в папки вида /mnt/systemN.

##### Шаг 2: Перейдите в вашу систему (chroot)

Теперь нужно "переключиться" внутрь вашей смонтированной системы, чтобы работать с ней как с основной. Обычно система монтируется в /mnt/system1. Выполните команду:

```bash
chroot /mnt/system1 /bin/bash
```
Если система смонтировалась в другую папку (например, /mnt/system2), укажите ее.

##### Шаг 3: Сбросьте пароль root

Теперь вы находитесь внутри вашей основной системы. Задайте новый пароль для пользователя root командой:

```bash
passwd
```
Вас попросят дважды ввести новый пароль. При вводе символы не отображаются — это сделано для безопасности.

##### Шаг 4: Выйдите и перезагрузитесь

После смены пароля выйдите из chroot-окружения:

```bash
exit
```
Затем перезагрузите компьютер:

```bash
reboot
```
После перезагрузки вы сможете войти в свою систему как root с новым паролем.
