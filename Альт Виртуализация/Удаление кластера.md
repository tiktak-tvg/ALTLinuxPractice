### Как корректно удалить кластер на единственном узле
Остановите службы кластера:
```bash
systemctl stop pve-cluster
systemctl stop corosync
```
Переведите файловую систему конфигурации в локальный режим:
```bash
pmxcfs -l
```
Используйте код с осторожностью.

Удалите файлы конфигурации кластера:
```bash
rm /etc/pve/corosync.conf
rm -rf /etc/corosync/*
```
Снова запустите службу конфигурации:
```bash
killall pmxcfs
systemctl start pve-cluster
```
### Как корректно удалить кластер из состава кластера
##### 1. Полное удаление виртуальной машины
Если вам нужно просто удалить конкретную ВМ, чтобы она перестала существовать в кластере:

a.Через веб-интерфейс:
- Выберите нужную ВМ в дереве ресурсов слева.
- Нажмите кнопку «Удалить» (More -> Remove) на верхней панели управления.
- Подтвердите действие, введя ID виртуальной машины.

b.Через командную строку (CLI):
 - Используйте команду qm destroy для ВМ или pct destroy для контейнеров:
```bash
qm destroy <VMID>
```
> - Примечание: ВМ должна быть выключена перед удалением. 

##### 2. Удаление узла (ноды) из состава кластера
Если задача состоит в том, чтобы вывести целый физический сервер из кластера, порядок действий следующий: 

- Освободите узел: Перенесите (мигрируйте) все работающие ВМ на другие узлы кластера или удалите их, если они больше не нужны.

- Отключите узел: Физически выключите сервер, который нужно удалить.

- Выполните удаление на рабочем узле:

- Зайдите по SSH на любой другой (остающийся в кластере) узел под учетной записью root.

- Посмотрите список узлов и их ID:
```bash
pvecm nodes
```
Удалите целевой узел по его имени:
```bash
pvecm delnode <Имя_узла>
```
Очистка (при необходимости): Если после удаления узел всё еще виден в интерфейсе как «неактивный», удалите его конфигурационную директорию:
```bash
rm -rf /etc/pve/nodes/<Имя_удаленного_узла>
```
