### Как корректно удалить кластер на единственном узле
Остановите службы кластера:
```bash
systemctl stop pve-cluster
systemctl stop corosync
```
Используйте код с осторожностью.

Переведите файловую систему конфигурации в локальный режим:
```bash
pmxcfs -l
```
Используйте код с осторожностью.

Удалите файлы конфигурации кластера:
```bash
rm /etc/pve/corosync.conf
rm -rf /etc/corosync/*
```
Используйте код с осторожностью.

Снова запустите службу конфигурации:
```bash
killall pmxcfs
systemctl start pve-cluster
```
